## 📂 Testing Deliverables & Artifacts

My portfolio is structured around the standard **Software Testing Life Cycle (STLC)**, containing production-grade deliverables across 5 core phases:

1. **Requirement Analysis & Strategy** (`1_Requirement_Analysis/`)
   * [`BluShop_Test_Plan.pdf`](./Projects/BluShop_Ecommerce/1_Requirement_Analysis/BluShop_Test_Plan.pdf) & [`MASTER_TEST_PLAN.md`](./Projects/BluShop_Ecommerce/1_Requirement_Analysis/MASTER_TEST_PLAN.md): Formal Master Test Plan outlining testing scope, risk analysis, test strategy, resource allocation, and pass/fail criteria for BluShop E-commerce.

2. **Test Design & Case Specifications** (`2_Test_Design/`)
   * [`Test_Case_Matrix.xlsx`](./Projects/BluShop_Ecommerce/2_Test_Design/Test_Case_Matrix.xlsx): Standardized Test Case Suite detailing test scenarios, precondition, steps, expected vs. actual results, and coverage across Happy Paths, Boundary Value Analysis (BVA), and Security Edge Cases.

3. **Test Execution & Defect Reporting** (`3_Test_Execution/`)
   * [`Bug_Report.pdf`](./Projects/BluShop_Ecommerce/3_Test_Execution/Bug_Report.pdf): Professional Defect Log containing severity/priority triage, reproducible steps, expected/actual behaviors, Root Cause Analysis (RCA), and recommended developer remediations for critical logic bugs.

4. **API Testing & Integration** (`4_API_Testing/`)
   * [`Postman_Collection.json`](./Projects/BluShop_Ecommerce/4_API_Testing/Postman_Collection.json): Executable Postman API Collection designed to validate HTTP status codes, JSON response schemas, and payload injection attacks against backend cart and checkout endpoints.

5. **Database Integrity & Verification** (`5_Database_Testing/`)
   * [`Validation_Queries.sql`](./Projects/BluShop_Ecommerce/5_Database_Testing/Validation_Queries.sql): SQL test scripts used to audit database state transitions, verify transactional integrity (ACID), and ensure accurate stock synchronization.
